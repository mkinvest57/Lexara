# Immerli Web

Next.js application for Immerli’s marketing site and browser learning experience.

```bash
pnpm --filter @immerli/web dev
pnpm --filter @immerli/web type-check
pnpm --filter @immerli/web build
```

The app runs at `http://localhost:3000`. Configure local values from `.env.example`; never commit production secrets.

Demo credentials: `demo@immerli.com` / `demo123456`.
