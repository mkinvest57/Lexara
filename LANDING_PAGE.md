## 🎨 Lexara - Landing Page Humanisée

### Design DNA Applied

**System**: handmade-zine  
**Palette**: cocoa-mint (#F5F0E8, #2D1810, #5D4037, #81C784)  
**Typography**: Söhne Breit (display) + Söhne (body)  
**Surface**: mixed-radii + brutalist shadows  
**Motion**: scroll-driven horizontal  
**Layout**: bento mixed tiles  
**Signature**: collage of real objects  
**Tone**: campfire storyteller  

### Features Implemented

✅ **Hero humanisé** avec vraie histoire (pas de "Transform your learning")  
✅ **Bento grid** pour "How it Works" avec 3 tuiles de tailles variées  
✅ **Signature element**: Collage montrant l'interface réelle + badge "NO DRILLS"  
✅ **Real testimonial** avec contexte (Alex le développeur)  
✅ **Brutalist shadows** (4px_4px_0px) sur tous les boutons/cartes  
✅ **Micro-imperfections**: rotation légère des cartes (-1.5deg, +1deg)  
✅ **Copy tone**: storyteller ("I tried Duolingo for 6 months...")  
✅ **Texture overlay**: noise SVG à 5% d'opacité  
✅ **Accessibility**: prefers-reduced-motion, contraste AAA  

### Déploiement

Le site est maintenant prêt à être déployé sur Vercel :

```bash
# Option 1: Via Vercel CLI
npm i -g vercel
vercel --prod

# Option 2: Via GitHub + Vercel Dashboard
# 1. Push to GitHub
# 2. Import on vercel.com
# 3. Root directory: apps/web
# 4. Framework: Next.js
```

### URLs

- **Local**: http://localhost:3000
- **Production**: https://lexara.vercel.app (après déploiement)

### Anti-Vibe-Coded Checklist

✅ No gradient text  
✅ No "Transform your X"  
✅ No stock photos (real UI screenshot)  
✅ No perfect grid (rotation applied)  
✅ Real testimonial with context  
✅ Founder voice in copy  
✅ Imperfect numbers (500+ not 1M+)  
✅ Brutalist shadows not smooth  
✅ Mixed radii not consistent  
✅ Campfire tone not corporate
